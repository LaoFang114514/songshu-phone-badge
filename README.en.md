A simple and easy-to-use phone badge creation tool that turns your idle old phone into a personalized fursuit badge display, perfect for furries who need a badge but are on a budget.

---

## ✨ Features
### 🖼️ Badge Management
- **Image / Video Dual Mode** — Import images or videos as badges, freely switch between displays
- **Create & Edit** — Built-in cropping tool to select and crop image areas for badges
- **List Management** — Rename, move up/down, delete — easily manage multiple badges
- **Selection Highlight** — The active badge is highlighted with a themed border for easy identification

### 🎬 Fullscreen Display
- **Immersive Experience** — Fullscreen badge display with auto-hidden system bars
- **Gesture Controls** — Long press to rotate badge (180° flip), pinch to exit playback
- **QR Code Display** — Swipe up to show a QR code popup, supports custom QR code images

### ⚙️ Practical Settings
- **Reverse Display** — Auto-flip 180° on launch, suitable for inverted placement
- **Always-On Display** — Screen stays on during playback, no auto screen-off
- **Battery Display** — Shows current battery percentage at the top during fullscreen
- **Lock Orientation** — Disable long-press rotation, fix badge orientation
- **Burn-in Protection** — Slightly shifts the display every 5 minutes to prevent OLED burn-in

### 💾 Data Backup
- **Local Import/Export** — Pack settings and images into a ZIP file for easy migration
- **WebDAV Cloud Backup** — Upload to or restore from a WebDAV server

## 📱 System Requirements

- **Minimum Version**: Android 5.0
- **Recommended Version**: Android 8.0 and above
- **Architecture Support**: armeabi-v7a / arm64-v8a

> Only tested on a 32-bit Android 6.0 device. Compatibility with other phones is not guaranteed.
